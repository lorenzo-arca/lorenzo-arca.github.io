# Institution logos

Drop logo files here using the filenames referenced in `data/authors/me.yaml`:

- `snb.png` — Swiss National Bank
- `uzh.png` — University of Zurich
- `bankitalia.png` — Banca d'Italia
- `bocconi.png` — Bocconi University
- `europe-economics.png` — Europe Economics

Notes:
- Formats `.png`, `.jpg`, `.svg`, `.webp` all work. Match the filename exactly to what's in `me.yaml`.
- Square logos (or near-square) render best in the round timeline marker.
- ~200×200 px is plenty (the marker shows them at 32×32). PNG with transparent background looks cleanest.
- Once the file is here, just refresh — no rebuild needed.

If a logo file is missing, that experience entry falls back to the default briefcase icon.
